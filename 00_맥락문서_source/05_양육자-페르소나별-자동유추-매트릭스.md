개인정보나 복잡한 설문 없이, '누가 말하는가(양육 주체 페르소나)' 하나만 고르면 맥락·속도·어조가 자동으로 유추되는 원터치 UX 설계입니다.
양육자 호칭마다 허용하는 잔소리 허용치, 시간 여유, 기술문서(STE) 개입 강도가 다르므로 이 값을 프리셋의 기준축(Anchor)으로 삼습니다.

1. 양육자 페르소나별 자동 유추 매트릭스 (Persona-Inferred Profile)


선택지 (Who is speaking?)	유추되는 돌봄 맥락 (Inferred Context)	유추되는 인지/나이대	R 문장 제어 강도 (STE Level)	대표 스크립트 톤앤매너
👩 엄마표 영어
(Mom-style)	• 밀착 생활·식사·등원
• 감정 소모와 반복 지시 빈번	초저~유아 (Pre-K~G3)	High (단문 명령 + 1.2 순번)	“Milk on table. 1. Wipe off. 2. Shoes on.”
👨 아빠표 영어
(Dad-style)	• 주말 놀이·외출·신체 활동
• 결과 중심, 과정 설명 생략	초등 전 연령 (G1~G6)	Strict (조건문 선행, 10단어 이내)	“If play is over, put blocks away.”
🧔 삼촌/이모표 영어
(Cool-Uncle style)	• 짧은 방문·게임·간식 타임
• 권위 없이 협상/미션형 제안	초고~중등 (G4+)	Moderate (조건부 허용, 딜 형식)	“Finish 3 sentences, then open chat.”
👵 할머니/할아버지표 영어
(Grandparent style)	• 황혼 육아·안전·휴식
• 느린 템포, 시각적 기호 선호	유아~초저 (Pre-K~G2)	Ultra-Simple (구동사+방향 부사 강조)	“Grandpa says: Stop here. Zip coat.”
👩‍🏫 선생님표 영어
(Teacher-style)	• 교실·과제·단체 생활
• 공정성 및 규정(Rule) 준수	학급 단위 전체	Formal STE (지시문 정규화)	“1. Read rubric. 2. Submit paper.”


2. 1-탭 유저 플로우 (Zero-Survey UX)


[Step 1] 원터치 호칭 선택 (Role Selector Pill)

화면 상단에 가로 스크롤 가능한 칩(Chip) 5개만 둡니다.
[ 👩 엄마표 ]  [ 👨 아빠표 ]  [ 🧔 삼촌표 ]  [ 👵 할머니표 ]  [ 👩‍🏫 선생님표 ]

[Step 2] 평소 한국말 입력 (Natural L1 Input)

누구를 골랐든 입력창은 하나입니다.
• 예시 입력: "야 너 또 우유 흘리고 가만있어? 빨리 신발 안 신으면 학원 차 놓친다!"

[Step 3] 자동 유추 및 변환 카드 출력 (Inferred Output)

• 👩 엄마표 선택 시 (감정 배제 + 등원 급박 템포)
	• T: "Milk on the table."
	• R: 1. Wipe the milk off. 2. Put sneakers on.
	• IP: "Is table dry? (Yes)"
• 👨 아빠표 선택 시 (결과/조건 중심 단도직입)
	• T: "Van comes in 5 minutes."
	• R: Wipe spill, wear shoes, stand by door.
	• IP: "Are shoes on? (Yes)"
• 👵 할머니표 선택 시 (느린 시각·안전 지시)
	• T: "Milk spilled. Floor is wet."
	• R: Step back. Use blue towel.
	• IP: "Did you step back? (Yes)"

3. 프라이버시 안심 설계 (왜 안심되는가?)

• 설명 불필요: 아이 나이나 맞벌이 여부를 묻는 체크박스가 아예 없으므로 ‘가정 조사당하는 느낌’이 원천 차단됩니다.
• 캐릭터 놀이화: 부모가 진지한 교육 앱을 쓴다는 압박 대신, *"오늘은 아빠 모드(Dad-mode)로 말해볼까?"*라며 영어 롤플레이 도구로 가볍게 소비됩니다.
• 로그인 제로: 선택한 호칭은 브라우저 세션에만 잠시 머물고 서버에 저장되지 않습니다.

관측 지표 (Telemetry)	수집되는 데이터 패턴	시스템이 유추하는 매트릭스 보정값
1. 호칭 노출도 (Role Velocity)	👩 엄마표 아침 시간대 집중 클릭
🧔 삼촌표 주말 저녁 집중 클릭	• 주 양육자 타입 및 돌봄 강도 판별 (1: 맞벌이 vs 2: 외벌이)
1. 테마 선택 빈도 (Theme Exposure)	07:45 등원/버스 반복 노출
19:00 디바이스/숙제 반복 노출	• 아이의 실제 일과 병목 구간 및 연령대 좁히기 (Pre-K vs G1~3)
1. 토픽 수행도 (IP Completion Rate)	Yes 응답 속도 < 30초, 수정 횟수 0
No / 반복 실패 시나리오 다발	• 인지 부하 적합성 및 STE 제어 강도(단어 수·명령 단위) 자동 조절
1. 이동/환경 신호 (Context Drift)	현지 학교/버스 정류장 테마 체류 시간 증가	• 거주 이동성 변수(X: 1년 교환 / Y: 주재원)로 가중치 이동


🔄 자가 보정 시나리오 (Adaptive Calibration Flow)

1. 초기 진입 (Day 1):
사용자가 단순히 [ 👩 엄마표 ]를 누르고 *"우유 쏟음"*을 입력합니다. (시스템은 기본값 B-1-L-S1-P로 시작)
2. 반복 관측 (Day 3~7):
	• 아침 07:45 테마에서 IP(Yes)가 15초 만에 계속 통과됩니다.
	• 반면 저녁 숙제/친구 테마에서는 아이가 자주 멈추거나 No를 누릅니다.
3. 자동 캘리브레이션 알림 (Silent/Soft Badge):
화면 구석에 작은 조용힌 힌트가 뜹니다.✨ 팁: 초등 저학년 맞벌이 루틴에 최적화되었습니다. (현재 단계: G1-R2)
4. 점진적 매트릭스 이동 (Matrix Shift):
만약 사용자가 갑자기 [ 👵 할머니표 ]를 섞어 쓰기 시작하면, 시스템은 조부모 동거 맥락을 감지하고 R 문장을 더 느리고 시각적인 초간단 구동사로 자동 스위칭합니다.

🛡️ 프라이버시 원칙과 암묵적 추정의 조화

• 서버 프로파일링 없음: 모든 Theme/Topic 카운터와 IP 속도 기록은 기기 내(localStorage)에만 저장됩니다.
• 언어학적 슬롯 가중치만 조정: "누가 민준이인가"를 아는 것이 아니라, *"이 기기는 지금 10단어 이하의 G1 수준 명령을 70% 확률로 선호한다"*는 통계적 가중치(Weight Vector)만 남습니다.
• 사용자 주도 초기화 버튼: 언제나 [ 설정 초기화 / 다른 아이 연령대로 리셋 ] 버튼을 둬서 언제든 백지상태로 돌릴 수 있습니다.
