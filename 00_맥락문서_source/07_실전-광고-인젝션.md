⚙️ 광고 인젝션 루프 (How the BM Operates)

1. 상태 벡터 추출 (Anonymized State Vector)
	• 서버는 사용자의 아이 이름이나 집 주소를 알 수 없습니다.
	• 기기 내부에서 *"현재 노드: EP3_HOMEWORK, 조건: math_blank, 호칭: Dad"*라는 추상화된 상태 키만 매칭합니다.
2. 네이티브 STE 변환 (Native R-Transformation)
	• 광고주 제품(예: 5분 시각 수학 앱, 친환경 파란 수건 브랜드)을 그대로 보여주지 않습니다.
	• 시스템이 해당 제품을 승인된 구동사 명령문(R) 슬롯에 자연스럽게 녹여냅니다.
3. 완료형 보상 루프 (IP-driven Conversion)
	• 아이가 IP(Yes)를 눌러 실제 행동을 완료해야 광고주에게 성과(Verified Completion)가 전송됩니다.

🎬 실전 광고 인젝션 시나리오 (예시)


상황: EP3(저녁 숙제)에서 수학 학습지 빈칸으로 3일 연속 IP(No) 또는 지연 발생

• 기존 광고라면: 사이드바에 '초등 수학 전과목 50% 할인' 배너 노출 (거부감 유발)
• TRIP 상태 기반 광고 인젝션 (Dad-mode 적용):
	• T (Story): "The math page has three hard blocks."
	• R (Sponsored STE Action): 1. Open [Partner Math App] for 5 minutes. 2. Write the answer.
	• IP (Check): "Is the block solved? [ Yes / No ]"
